OTF exercise directory

An unofficial fan directory helps visitors recognize an exercise and reach an attributed demonstration before class. Coaching resources form a separate catalog for technique, class delivery, programming, and safety context.

The reviewed catalog is the source of truth. Preserve names, metadata, summaries, creator credit, original-source links, and reviewed legacy destinations. Search uses Fuse.js with URL-backed multi-select filters and bounded 24-item pages. No accounts, workout builders, generated advice, rankings, or invented durations belong to this product.

Local previews load without third-party media. TikTok players require explicit activation; Instagram opens the source post. Production uses Vercel Web Analytics as described on the privacy page. Keyboard access, mobile touch targets, reduced motion, and existing no-JavaScript navigation are release requirements.
